## 4. Бүтээлч шийдэл ба demo

**Digital Time Capsule:** зочин болон оюутан ирээдүйн оюутанд захиа, дурсамж, зөвлөгөө үлдээнэ. Захиа өгөгдлийн санд хадгалагдаж, админ хянасны дараа нийтэд харагдах хананд гарна. Ингэснээр музей нь өнгөрсөн бүтээлийг хадгалахын зэрэгцээ үе үеийн оюутны харилцааг үргэлжлүүлнэ.

- [5–7 минутын demo: ярих текст ба дэлгэцийн үйлдэл](demo-script-mn.md).
- Demo нь танилцуулгын үеэр апп дээр шууд үзүүлэхэд зориулсан. Бичлэг энэ багцад ороогүй.

## Шалгалтын нотолгоо

[Дэлгэрэнгүй шалгалтын тайлан](supabase-verification.md).

- 6 unit/regression тест, production build амжилттай.
- Хиймэл API-тай browser тестээр CRUD, профайл, gallery upload, capsule moderation, архив import/retry шалгасан.
- Серверийн RLS тестийг хэрэглэгч SQL Editor-д ажиллуулж PASS болсныг баталгаажуулсан.
- Нийтийн URL дээр бодит Supabase-ийн 5 хүсэлт HTTP 200; 7 бүтээл, 10 багш, 5 арга хэмжээ, цомгийн зураг ачаалсан.
- 360/390/768/1440 px өргөнд халилтгүй, browser exception 0.
- Нийтийн domain дээр account-аар binary upload болон email recovery урсгалыг read-only smoke тест хийгээгүй.

## Багцын бүтэц

- `README.md`: суулгах болон ажиллуулах заавар.
- `docs/`: хүлээлгэн өгөх тайлбар, ERD, wireframe, demo текст, эх сурвалж, тестийн нотолгоо.
- `src/`, `public/`: веб аппын эх код, зураг.
- `supabase/`: schema, шинэчлэлт, seed, RLS шалгалтын SQL.
- `tests/`: unit болон browser тестүүд.
- `scripts/`: агуулгын SQL үүсгэх скрипт.

Локал `.env.local`, credential, `node_modules`, `.git`, түр QA файлууд ZIP-д ороогүй. Шинэ орчинд README-ийн дагуу өөрийн Supabase тохиргоог оруулна. Багцын эх кодын commit-ийг `SUBMISSION_VERSION.txt`-д тэмдэглэнэ.
